Dithervatar

Deterministic avatars from any string. Wallet address, username, or anything else.

Add it to your project

A square canvas, one call, no dependencies. Works in any framework or plain HTML.

npm install dithervatar
import { renderDithervatar } from 'dithervatar';

const canvas = document.querySelector('#avatar');

renderDithervatar(canvas, {
  hash: '0x742d35cc6634c0532925a3b844bc454e4438f44e',
  size: 128,
});
hash
Any string. The same one always draws the same avatar.
size
Square canvas size in CSS pixels, 64 by default.
animated
Runs the dither loop on requestAnimationFrame until you call the returned cancel.
